Web Automation as asked with Python and Robot Framework

This project automates 3 simple testcases using Robot Framework and Selenium Library on the website - https://practicetestautomation.com/practice-test-login/

Test Scenarios
1. Valid Login
2. Invalid Login
3. Asserting the elements and logging out

Tools used
1. Robot Framework
2. Selenium Library
3. Chrome Driver

guide on how to run --
pip install -r requirements.txt
robot tests
